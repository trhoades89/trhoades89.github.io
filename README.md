## England School Map (`/schools/`)

A static map of every open school in England with Ofsted judgements, exam results
(KS2, KS4, 16–18), admissions demand and an approximate catchment.

- Front end: `schools/index.html`, `schools/app.js`, `schools/app.css` (Leaflet, vendored in `schools/vendor/`).
- Data: `schools/data/`, generated by `scripts/build_school_data.py` from GIAS, Ofsted management
  information, DfE performance tables and DfE applications & offers (all Open Government Licence).
- The **Build school data** workflow (`.github/workflows/build-school-data.yml`) rebuilds the data every
  Monday and commits it; run it manually from the Actions tab to refresh sooner.
- Local rebuild: `pip install pyproj && python3 scripts/build_school_data.py --cache /tmp/school-cache`.
